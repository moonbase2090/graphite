# Security

If you believe you have found a security vulnerability in Graphite, please email **security@moonbase2090.com**.

Include:
- What you found and where it applies (a crate, a release build, or CI)
- Steps to reproduce
- Impact if you know it

Please do not open a public GitHub issue for security-sensitive reports. We will acknowledge your message and work on a fix.
