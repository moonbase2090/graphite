# Security

If you believe you have found a security vulnerability in Graphite, please report it privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. This keeps the report private until a fix is ready.

Include:
- What you found and where it applies (a crate, a release build, or CI)
- Steps to reproduce
- Impact if you know it

Please do not open a public GitHub issue for security-sensitive reports.
